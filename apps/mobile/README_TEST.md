# 🚀 Test Rehberi - Hızlı Başlangıç

Arkadaşlarınızla test etmenin en hızlı yolu.

## ⚡ 2 Dakikada Test Et (Ücretsiz)

```bash
cd apps/mobile
npm run test:expo-go
```

**Ne olur:**
1. Terminal'de QR kod görünür
2. Screenshot al ve paylaş
3. Test kullanıcıları "Expo Go" ile tarar
4. Uygulama açılır! 🎉

---

## 📱 Test Kullanıcıları İçin

### iOS & Android
1. App Store/Play Store'dan **"Expo Go"** indirin
2. Size gönderilen **QR kodu** tarayın
3. Uygulama açılır!

---

## 🎯 Diğer Seçenekler

### Tüm Özellikleri Test Et (Development Build)
```bash
npm run build:dev-apk
```
- ✅ IAP, bildirimler, vb. çalışır
- ⏱️ 20 dakika build süresi
- 🔄 QR kod ile güncelleme

### Standalone Uygulama (APK)
```bash
npm run build:demo:android
```
- ✅ Tam uygulama
- ⏱️ 20 dakika build süresi
- 📦 APK dosyası
